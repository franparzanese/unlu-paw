# unlu-paw

Trabajos prácticos de la asignatura "Programación en Ambiente Web" de la Universidad Nacional de Luján.

## Introducción

A lo largo de todos los trabajos prácticos se construirá la web de una institución de salud, que permite a los pacientes conocer las especialidades del lugar y solicitar turnos.

## Esquema de versionado

Los trabajos prácticos se encuentran divididos en 5 enunciados (adjuntos en el directorio `enunciados`) que van incrementando la funcionalidad y la estética del sitio web. Se generarán versiones de este proyecto a medida que se vayan completando los enunciados, conforme a la siguiente tabla:

| Enunciado | Versión  | Entregado |
|:---------:|:--------:|:---------:|
| TP 1      | `v0.1.x` | -         |
| TP 2      | `v0.2.x` | -         |
| TP 3      | `v0.3.x` | -         |
| TP 4      | `v0.4.x` | -         |
| TP 5      | `v1.0.x` | -         |
